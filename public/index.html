Gmail

Checking connection…

Use Google’s account sign-in and consent screen to authorize Gmail API access; this does not sign you in to Friday. Friday requests read-only Inbox headers and unread status. Google access and refresh tokens stay in private files on this host. Friday fetches metadata on demand; it does not read message bodies, send mail, or cache message history.

Slack

Checking connection…

Use Slack’s OAuth screen to authorize/install Friday in a workspace; workspace-admin approval may be required. This is separate from Friday app login. Friday stores the Slack bot token privately on this host. Access is read-only and limited to selected public channels: no DMs, search, or posting. Chat excerpts may remain in transcripts and enabled GitHub snapshots, but not daily memory or connector cache.

GitHub sync

Syncs ~/.friday/ to one private GitHub repository (created if missing). Files named auth.json, repositories, memory/, node_modules, .git metadata, and symlinks are excluded. Other settings and conversation history may contain sensitive data; existing remote auth.json copies are not removed.
